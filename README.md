# WIN100-64-bit-ISO
Windows 1.0 to run on Modern computers 64-bit/x64. It's on under construction so it will be released soon.
## Notice
> ⚠️ This project is not from Microsoft. This project isn't original, some code may be modified or edited.
## Directions of use
> Install this ISO files at releases page of latest version.
> Open File Explorer and locate the downloaded file (It may be on %userprofile%/Downloads), and right click on it.
> Click Burn or Mount and use your USB Drive to write the data
> Enjoy! Click on WIN.exe and it will run **MS-DOS Executive** and have fun.
